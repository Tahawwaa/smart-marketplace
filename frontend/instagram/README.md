# تصاویر پروژه برای اینستاگرام

## ساختار
- `screenshots/` — اسکرین‌شات‌های خام سایت (PNG، رزولوشن ۲x)
- `posts/` — ۶ اسلاید آماده‌ی پست/کاروسل اینستاگرام (۱۰۸۰×۱۳۵۰، نسبت ۴:۵)

## اسلایدها
1. کاور: معرفی پروژه
2. نسخه‌ی دسکتاپ، تم روشن و تیره
3. نسخه‌ی موبایل
4. قابلیت‌ها (سه پنل + موجودی هوشمند)
5. استک فنی
6. اسلاید پایانی / دعوت به همکاری

## نحوه‌ی گرفتن اسکرین‌شات‌ها
```bash
npx vite --host 127.0.0.1 --port 5173
google-chrome --headless=new --no-sandbox --hide-scrollbars \
  --window-size=1440,900 --screenshot=desktop.png http://127.0.0.1:5173/
```

برای تغییر متن یا رنگ اسلایدها، فایل `slides.html` (کنار همین README) را ویرایش کنید و با اسکریپت `render.mjs` دوباره رندر بگیرید.
